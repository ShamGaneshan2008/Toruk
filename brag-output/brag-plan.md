# Brag Plan: Toruk-LM

## What is this app?
Toruk is a language-model research foundation testing whether bounded memory can retain, revise, and preserve information across long streams.

## The angle
A cinematic research trailer built around one question: what should a model remember when the facts change? The film moves from the research objective to the verified causal-LM pipeline, then shows the real local continuation interface and an actual saved continuation. It closes honestly: the memory advantage is still a research goal.

## Hook (first 2–3 seconds)
On near-black, the words “WHAT SHOULD A MODEL REMEMBER?” arrive over a thin blue state line. A second fragment, “WHEN FACTS CHANGE?”, takes focus.

## Key moments
- A small record changes city from Pune to Jaipur while “botanist” stays put. This is the README's illustrative objective, explicitly marked as an objective, not a result.
- The research pipeline appears: ordinary causal LM, bounded memory prototype, independent evaluation. The ordinary model is verified; the memory advantage is not.
- Recreate the actual local chat UI and show a saved, repetitive `abc` continuation from `artifacts/minimal-lm-demo-001/eval/predictions.json`, labeled as a saved text-continuation example.

## Outro / punchline
“REMEMBER WHAT MATTERS. REVISE WHAT CHANGED.” Then “TORUK-LM / RESEARCH PROTOTYPE”.

## User flow worth showing
Open the experimental local page → enter a text prefix → inspect a generated continuation. The on-screen output is a documented saved example, not a new live inference.

## Tone
- Preset: cinematic
- Creative direction: restrained scientific trailer; large editorial type, precise diagrams, deep blue light, no victory claim
- Interpretation: dramatic movement and sound carry the energy while technical claims stay cautious.
