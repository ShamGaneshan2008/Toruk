## End-to-end trace

An ordinary fixture document from `data.make_fixture` (`src/toruk_lm/data.py`) is UTF-8 encoded by `ByteTokenizer` (`tokenizer.py`): PAD=0, BOS=1, EOS=2, bytes=3..258. `data.windows` creates `x=tokens[:-1]` and `y=tokens[1:]` in nonoverlapping context windows; `data.batch` marks padded targets -100. `model.CausalLM` applies causal attention and `loss_sum` computes cross entropy only on valid targets (`model.py`). `engine.train` reads only its train path for updates, checks train/validation ID and exact-text separation, saves model/config/tokenizer fingerprint and dataset hashes in a checkpoint, and computes validation loss without updates (`engine.py`). `engine.load_model` checks format, fingerprint, config/state compatibility and finite weights. `model.generate` greedily recomputes the last context window, excludes PAD/BOS, and stops on EOS or the token cap. `ByteTokenizer.decode` discards special IDs and decodes generated bytes. `engine.evaluate` records half-document continuation plus a reference suffix, and reports loss and generation counts, **not continuation accuracy**.

The controlled-world path (`worlds.py`, `controlled.py`, `reproducibility.py`) assigns train/validation/test world identities before generation; `train_controlled` loads train worlds for updates and validation worlds for checking. Generation sees history and question; the oracle answer enters teacher-forced loss during training and offline scoring during evaluation. The scorer takes the first newline-delimited decoded line and compares it exactly with the oracle answer. The smoke config (`configs/reproduce-smoke-v1.json`) fixes two worlds per split, two optimizer steps, and a two-token answer cap. The cap cannot express longer gold values such as dates; it makes that smoke score unsuitable as a general language or recall measure. The ordinary model's 64-token local context also omits most long world histories. This is a measurement limit, not a verified code defect.

No out-of-vocabulary ID, target shift, split leak, checkpoint mismatch, unbounded generation, or parsing mismatch was reproduced in the inspected paths. The fixture is only 60 highly templated documents (48 train, six validation, six test); a low byte loss on it does not establish robust language modeling.
