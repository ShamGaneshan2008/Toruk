## Resulting local implementation

Added **Qwen/Qwen2.5-0.5B-Instruct**, pinned to
`7ae557604adf67be50417f59c2c2f167def9a775`, with safetensors SHA-256
`fdf756fa7fcbe7404d5c60e26bff1a0c8b8aa1f72ced49e7dd0210fe288fb7fe`.
The weight file was downloaded and independently hashed locally: 988,097,824 bytes.
The public source metadata identified the same revision/hash. It is a third-party
instruct backbone, Apache-2.0 ([official card](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct)).
Qwen supplies language ability; Toruk did not train or fine-tune it.

The same local-only loader, authenticated inference service, killable worker and
web proxy now accept either allowlisted backbone manifest. Qwen uses general
conversation instructions covering direct answers, user facts, corrections,
uncertainty and missing information. The selected-token measurement includes those
instructions. SmolLM retains its original formatting for historical reproducibility.
No research checkpoint format, training pipeline or archived evaluation was changed.
The downloader defaults to Qwen; historical SmolLM docs and Docker build explicitly
select `--model smollm2` so deployment cannot silently switch models.

Limits remain 512 prompt tokens, 64 output tokens, 20 messages, 1,024 bytes/message,
8,192 history bytes, 16,384 request-body bytes, one simultaneous generation,
eight HTTP connection threads, 45-second killable generation timeout and 60-second
proxy timeout. Tokens from dropped history are still counted in full input.
This is bounded recent-context inference, not persistent memory.
No raw messages are logged by the servers; only the deliberately synthetic probe
artifacts contain prompts and answers. Credentials remain server-side.

## Real final prompt/response examples

All examples below were run through the Node web proxy with the resulting Qwen
backend. They are verbatim; no example output was invented.

1. User: `What is 2 + 3?`

   Assistant: `The answer to 2 + 3 is 5.`

2. User: `In one sentence, what do plants use sunlight for?`

   Assistant: `Plants use sunlight to produce food through photosynthesis.`

3. Actual multi-turn history:

   User: `My bicycle lock code is CEDAR-27. Remember it for this conversation.`

   Assistant: `The user's bicycle lock code is CEDAR-27.`

   User: `What is the capital of Japan?`

   Assistant: `The capital of Japan is Tokyo.`

   User: `What bicycle lock code did I give you earlier?`

   Assistant: `You gave me the code CEDAR-27.`

Additional actual final responses:

- `What is the capital of France?` → `The capital of France is Paris.`
- After name setup and generated reply, `What is my name?` → `Your name is Mira.`
- After color setup and generated reply, `Correction: my favorite color is green. What is my favorite color now?` → `Green is my favorite color now!` (**attribution failure**).
- `What is the name of my childhood teacher? I have not told you. If you don't know, say so.` → `I'm sorry, but I don't have enough context or information to provide an accurate answer to your question. You haven't told me anything about who your childhood teacher was or if they're still with you. Without more details, I can't determine their name or confirm whether they've left your life.`
- `One note says my favorite season is summer. A second note says winter. I have not said which is correct. Without guessing, which season is my favorite?` → `Without knowing which notes were spoken or who made them, it's impossible to determine which season is your favorite.`

## Remaining blocker and Git state

chatbot still needs stronger conversational reliability (including attribution),
restoration of the original selector, and a newly frozen same-backbone held-out
comparison before any efficiency claim. Hosting and an interactive browser preview
remain unverified. Restoring the evaluated selector requires the exact original
checkpoint with SHA-256
`479c5ee26ff907783018fcaf9004d2b072610793f019648735d7405bc2ec156d`;
requesting TORUK without it is deliberately rejected.

All work is local on `main`; files above are modified/untracked. Nothing was
committed, pushed, uploaded to a hosting account or deployed. Only public model
files were downloaded. Large model files are ignored.
